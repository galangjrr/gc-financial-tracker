## 🔥 Fitur-Fitur Kece

- 📊 **Beranda & Pantau Duit**: Dashboard visualizer mantap pake **Recharts**, pantau arus kas tanpa pusing.
- 💳 **Dompet Multi-Wallet**: Pisahin duit jajan, tabungan, sm dompet darurat.
- 🍕 **Budgeting (Alokasi Kebutuhan)**: Set limit pengeluaran bulanan biar ga bablas beli kopi kekinian.
- 🤝 **Catat Utang (Debt Tracker)**: Biar ga lupa nagih ke temen yang pura-pura amnesia.
- 🎯 **Nabung (Target Goals)**: Fitur impian beli gadget baru / liburan tanpa *anxiety*.
- 👨‍👩‍👧 **Fitur Keluarga / Shared**: Kelola dompet bareng doi atau keluarga.
- 🤖 **AI Assistant**: Powered by **Google Gemini AI** buat kasih rekomendasi finansial yang presisi.

## 🛠️ Tech Stack Impian

- **Framework**: Next.js 16 + React 19 (Super Wusss! ⚡)
- **Backend & Database**: Supabase (Postgres, Realtime, RLS🔒)
- **Styling**: Tailwind CSS + Radix UI + Vaul (Bikin UI smooth abis)
- **State & Form**: React Hook Form + Zod (Form Validation tanpa drama)
- **Intelligence**: Google Generative AI (Gemini SDK)

## 🚀 Cara Run di Lokal (Buat yang Mau Ngoprek)

1. **Clone repo ini dulu, bang:**
   ```bash
   git clone https://github.com/galangjrr/gc-financial-tracker.git
   cd gc-financial-tracker
   ```

2. **Install dependencies (jangan lupa seduh kopi dulu):**
   ```bash
   npm install
   ```

3. **Setup Environment Variable (`.env.local`):**
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   GEMINI_API_KEY=your_gemini_api_key
   ```

4. **Gas Run Dev Server:**
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:3000` dan enjoy! 🎉
